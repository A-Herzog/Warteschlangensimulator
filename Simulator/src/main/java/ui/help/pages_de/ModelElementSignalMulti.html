Modell-Element: Mehrfachsignal

Passiert ein Kunde ein Mehrfachsignal-Element, so werden ein oder mehrere Signale ausgelöst. Schranken-Elemente können durch solche Signale benachrichtigt werden und wartende Kunden freigeben.

Einstellungen

Pro Signaldatensatz muss ein Signalname angegeben werden. Zusätzlich kann jeweils eine Zeitdauer eingestellt werden, um die die Auslösung des Signals nach dem Eintreffen des Kunden verzögert werden soll. Ist keine Verzögerungszeit eingestellt, so wird das Ereignis ausgelöst, sobald ein Kunde an der Station eintrifft.

Die optionale Bedingung ermöglicht es, dass nur unter bestimmten Voraussetzungen eine Signalauslösung erfolgt, wenn ein Kunde die Station passiert.
