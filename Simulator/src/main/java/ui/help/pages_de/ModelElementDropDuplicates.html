Modell-Element: Duplikate ausleiten

In ein "Duplikate ausleiten"-Element können beliebig viele Kanten einlaufen. Von den an der Station eintreffenden Kunden wird der Wert einer einstellbaren Eigenschaft erfasst. Wird mehrfach ein Kunde mit demselben Wert erfasst, so werden ab dem zweiten Kunden mit diesem Wert alle Kunden als Duplikate über die zweite auslaufende Kante aus der Station ausgeleitet. Lediglich der erste Kunde wird als neuer Kunde über die erste Kante weitergeleitet.

Einstellungen

Für das "Duplikate ausleiten"-Element kann ein Name eingestellt werden. Dieser hat jedoch keine weitere Bedeutung, sondern wird lediglich in der Komponente auf der Zeichenfläche angezeigt. Des Weiteren können der Index des Kundendatenfeldes, dessen Wert betrachtet werden soll, eingestellt werden und es kann angegeben werden, für wie lange die erfassten Werte vorgehalten werden sollen.
