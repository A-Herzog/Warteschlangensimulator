Model element: Duplicate

Any number of edges can go into a duplicate element. For each client arriving at the station, the value of an adjustable property is recorded. If a client with the same value is recorded more than once, starting with the second client with that value, all clients are routed out of the station as duplicates via the second outgoing edge. Only the first client is forwarded as a new client via the first edge.

Settings

The name of the duplicate element has no further meaning. In addition, you can set the index of the client data field whose value is to be considered, and you can specify how long the recorded values should be retained.
