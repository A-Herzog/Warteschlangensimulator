# EU-based download integrity checker for Warteschlangensimulator

Warteschlangensimulator ist developed in the EU. But its hosted on GitHub. The download checker allows a user to end-to-end check the integrity of the downloaded program file.

![EU-based download integrity checker for Warteschlangensimulator](https://a-herzog.github.io/Warteschlangensimulator/QSCheck/QSCheck.png)

Use this URL to validate your download:
* https://www.simzentrum.de/fileadmin/Simzentrum/QSCheck.html
